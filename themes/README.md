# Omarchy PC themes from OmarchyTV

- `omarchy-campfire-theme/`: the **campfire** theme for the Omarchy PC (the TV side is the `campfire` stock theme).
  Published on its own at https://github.com/piermark/omarchy-campfire-theme, which is what
  `omarchy-theme-install` uses. That repo also holds `extras/campfire-loop.mp4` (18 MB, the live fire for the PC):
  it is kept out of OmarchyTV, since the TVs draw the fire live with OmaFire's fire.js and never need it.
  Run `extras/install-live` from the installed theme (`~/.config/omarchy/themes/campfire/`), not from this copy.
